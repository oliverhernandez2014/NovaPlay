Microsoft Windows "Memphis" Project

Estás ejecutando una simulación de la compilación de desarrollo de 1997. Este proyecto se diseñó para reemplazar los parches rápidos de Windows 95.

Características principales en desarrollo:
• Soporte integrado para Concentradores de Bus Serie Universal (USB).
• Integración del motor de ejecución AGP para gráficos en 3D.
• Actualización del sistema al núcleo Internet Explorer 4.0.
